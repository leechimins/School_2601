## 요약
- 플레이어 캐릭터의 체력(HP)을 관리하기 위한 수치 데이터(`maxHp`, `currentHp`) 모델링 및 Start 초기화 완료
- UI Canvas 내 Filled 타입 Image의 `fillAmount`를 `currentHp / maxHp` 비율에 맞춰 실시간으로 갱신하는 연동 구현
- 오크와 플레이어 충돌 시 체력이 10 감소하고 충돌한 오크를 소멸시키는 피격 시스템 구현
- 피격 직후 0.5초 동안 데미지를 받지 않는 무적 프레임(Invincibility)과 피격 깜빡임 애니메이션(`Damaged` Trigger) 연동 적용
- 필드에 드롭된 물약을 플레이어가 먹었을 때 체력이 20만큼 회복되고 물약 오브젝트가 사라지는 회복 연동 완료

## 변경 범위
- `PlayerController.cs`: `maxHp`, `currentHp`, `invincibleDuration`, `isInvincible` 변수 추가. `DecreaseHp()`, `IncreaseHp()`, `UpdateHpUI()` 및 무적 처리 코루틴(`TriggerInvincibility()`) 구현. `OnCollisionEnter2D()` 내에 오크 충돌 데미지 연산 추가
- `ItemController.cs`: 플레이어와 Trigger 충돌 감지 시 `PlayerController.IncreaseHp(20f)`를 호출하도록 수정
