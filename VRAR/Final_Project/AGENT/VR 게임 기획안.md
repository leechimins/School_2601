## 1. 프로젝트명 및 게임 개요

오크와 궁수, 2D 탑뷰 핵 앤 슬래시 

### 1.1 게임 핵심 콘셉트 (Concept)

사방에서 몰려오는 오크들을 화살로 죽이고 회복 아이템(물약)을 통해 살아남는 2D 탑뷰 뱀서라이크 게임

### 1.2 게임의 목표 (Goal)

체력(HP)가 0이 되지 않도록 물약을 획득하면서 최대한 오랜 시간 동안 생존하여 최고 점수를 경신

### 1.3 핵심 플레이 방식

1. **시작**: 플레이어는 2D 탑다운 시점의 맵 중앙에서 꽉 찬 HP를 가진 상태로 시작합니다.

2. **조작**: 키보드 방향키 또는 WASD 키 입력을 통해 8방향으로 자유롭게 이동하며, 플레이어가 클릭한 방향을 향해 화살을 발사하여 오크를 사냥합니다.

3. **상호작용**:

   * **적의 공격**: 오크 제너레이터에 의해 화면 외곽에서 생성된 오크들이 플레이어를 실시간 추적하며 다가옵니다. 오크가 플레이어와 충돌하면 HP 게이지가 차감됩니다.

   * **사냥 및 파밍**: 플레이어의 화살에 맞은 오크는 소멸하며, 그 자리에 확률적으로 물약을 남깁니다. 플레이어가 이를 먹으면 HP가 회복되는 버프를 얻습니다.

4. **종료**: 플레이어의 HP가 0이 되면 씬이 전환되고 시간과 점수가 표시되며 끝납니다.

## 2. 게임의 재미 요소

### 2.1 물리적 피드백과 연출 효과

* **사냥 피드백 (파티클 시스템)**: 플레이어의 화살이 오크에게 명중하여 오크가 처치되는 순간, 둥근 링 형태의 파티클 이펙트가 소멸과 동시에 터져 피드백을 제공합니다.

### 2.2 동적 난이도 조절

* **시간 경과에 따른 웨이브 시스템**: 생존 시간이 30초를 초과할 때마다 생성되는 오크의 이동 속도와 리스폰 주기가 빨라집니다.

## 3. 게임 리소스 및 개발 상세 계획

### 3.1 화면 배치 오브젝트 리스트 (2D Game Scene)

#### **Player** : Rigidbody 2D, Box Collider 2D 적용

플레이어가 조작하는 캐릭터로 8방향 이동 및 플립북 애니메이션이 적용되며 적 및 탄막과의 충돌 판정을 수행합니다.

#### **Orc (Prefab)** : Rigidbody 2D, Box Collider 2D 적용

일정 시간마다 랜덤한 위치에 생성되어 플레이어를 추적하는 적 오브젝트입니다.

#### **Arrow (Prefab)** : Circle Collider 2D, Script 적용

플레이어가 발사하는 투사체로, 물리 엔진을 사용하지 않고 스크립트로 직선 이동하고 화면 밖으로 나가면 소멸합니다.

#### **DropItem (Prefab)** : Box Collider 2D (Is Trigger) 적용

오크 처치 시 확률적으로 생성되는 물약으로 플레이어 충돌 시 체력 회복 효과를 제공합니다. 추후 다른 버프를 제공할 수 있게 업데이트할 계획입니다.

#### **Game Director** : Script 적용

생존 시간, 스코어를 연산하고 UI 요소를 실시간으로 갱신하는 보이지 않는 오브젝트입니다.

#### **UI_Canvas** : Canvas, Image (HP Gauge), TextMeshPro

화면 우측 상단에 HP 게이지(Filled 타입)를 배치하고, 중앙 상단에 생존 시간 및 점수를 표시합니다.

### 3.2 주요 스크립트 기능 정의

#### **컨트롤러 스크립트**

* **PlayerController.cs**

  * 키보드 입력에 따른 8방향 이동을 구현하고, 마우스 클릭 지점의 좌표를 받아 해당 방향으로 플레이어의 화살(Arrow) 프리팹을 Instantiate합니다.

  * Order in Layer 속성을 배경보다 높게 유지하여 항상 화면 전면에 표시되도록 관리합니다.

* **EnemyController.cs**

  * 생성 시 씬 내부의 Player 오브젝트 위치(Transform)를 탐색하여 실시간으로 추적 이동합니다.

* **ArrowController.cs**

  * 발사된 시점에 설정된 방향 벡터를 기반으로 transform.Translate를 사용해 매 프레임 직선 고속 이동합니다.

  * 충돌을 판정하고, 화면 바깥으로 벗어날 경우 Destroy(gameObject)를 호출합니다.

#### **제너레이터 스크립트**

* **EnemyGenerator.cs**

  * 오크(Orc) 프리팹을 실시간 무한 양산하는 공장 역할을 합니다.

  * Time.deltaTime을 누적하여 플레이어의 현재 시야 밖 무작위 X, Y 좌표 외곽에서 일정 시간마다 오크를 동적 생성합니다.

* **ItemGenerator.cs**

  * 오크가 화살에 맞아 소멸하는 시점에 작동하거나 맵 곳곳에 주기적으로 아이템 프리팹을 생성합니다.

#### **감독 스크립트 (Director Scripts)**

* **GameDirector.cs**

  * 플레이어가 살아남은 시간과 처치한 오크 수를 기반으로 점수(Score)를 누적 계산합니다.

  * 플레이어가 적이나 탄막에 충돌하여 체력 감소 메서드(DecreaseHp)가 호출되면, UI Image의 fillAmount 값을 감산하여 HP 게이지를 시각적으로 업데이트합니다.

  * 플레이어의 HP가 0 이하가 되면 모든 생성기(Generator)와 오브젝트의 움직임을 정지시키고 화면 중앙에 최종 기록 결과창을 출력합니다.
